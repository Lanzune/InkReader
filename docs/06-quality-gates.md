# 质量门槛

本文件定义每个阶段必须守住的硬指标。任何放宽必须记录原因和测量数据。

## 1. 构建与合规

| 检查 | 门槛 |
|---|---|
| Debug 构建 | `:app:assembleDebug` 成功 |
| Release 构建 | R8 后成功，签名 APK 可安装 |
| 权限 | 主 APK 不声明 `INTERNET`；无危险权限 |
| 16 KB | 含 native 库时通过 `zipalign -c -P 16 -v 4` |
| 依赖 | 不引入 WebView、Readium、PDFium、Room、Hilt、OkHttp、图片加载库 |
| 许可证 | 只使用宽松许可证；发布时附清单 |

## 2. 体积与性能

| 指标 | B1 目标 | v1.0 目标 |
|---|---|---|
| arm64 release APK | ≤14 MB | ≤12 MB |
| universal APK | ≤20 MB | ≤18 MB |
| 冷启动（中端机） | ≤1.2 s | ≤1.0 s |
| 翻页 | 无明显卡顿 | 60 fps，P95 <16.7 ms |
| 10 MB EPUB 内存 | <180 MB | <150 MB |
| 100 MB TXT 首屏 | ≤3 s | ≤2 s |
| 缓存 | 仅封面 ≤16 MB | 仅封面 ≤16 MB |

## 3. 格式验收

| 格式 | 验收 |
|---|---|
| TXT | UTF-8/UTF-16/GB18030/Big5；BOM；章节识别；100 MB 不 OOM |
| EPUB | 语料库 ≥95% 可打开；不丢字、不重页；目录/封面/图片可用 |
| PDF | 常见文本/扫描 PDF 可显示；页面缩放不 OOM；异常文件友好报错 |
| HTML/MD | 脚本/远程资源阻断；基本块模型正确 |
| 不支持格式 | 显示可行动错误，不崩溃 |

格式语料放在 `docs/quality/corpus/`（样本本身不入库，只记录来源、哈希和预期结果）。

## 4. 插件验收

- manifest 非法、路径穿越、超大包、DEX/native 文件被拒绝。
- 插件可安装、启用、禁用、卸载。
- 插件死循环/超时/内存超限被隔离，阅读主链路不退出。
- 插件不能访问网络、任意文件、Android Context。
- API 主版本不匹配时拒绝激活，并给出提示。
- 至少一个主题插件和一个命令插件通过契约测试。

## 5. 隐私与缓存

- 主 APK 无 `INTERNET`。
- 不集成广告/统计/账号 SDK。
- 不缓存正文和页面；封面缓存有 LRU 上限；可清理。
- `allowBackup=false`；卸载不删除用户原始书籍。
- 日志默认不落盘；插件日志有上限。

## 6. 真机验收

项目所有者负责：

- 安装/升级/卸载
- 从系统文件选择器打开 TXT/EPUB/PDF
- 翻阅 50 页以上、旋转、分屏、后台恢复
- 明暗主题、亮度、字号
- 滑动/覆盖/淡入/折页
- 插件安装/禁用/安全模式
- 至少一台低端机或低内存场景

每次验收提供：Android 版本、机型、步骤、截图/录屏、相关 logcat。

## 7. 阶段闸门

| 阶段 | 必须通过 |
|---|---|
| M0 | 构建成功、无网络权限、git 提交 |
| M1 | 真机打开 TXT、翻页、插件主题/命令、崩溃不拖垮阅读 |
| M2 | 进度恢复、100 MB TXT、日夜/亮度 |
| M3 | EPUB 语料 ≥95%、无丢字、TOC/封面 |
| M4 | PDF 页面/缩放、HTML/MD 阻断远程资源 |
| M5 | 60 fps、低端机降级、折页可关闭 |
| M6 | 插件隔离/超时/版本拒绝、示例插件 |
| M7 | 体积/16 KB/权限/P0 全部通过 |
