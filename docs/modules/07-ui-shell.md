# 模块 07：UI 壳层

**代码：** `app`  
**阶段：** M1 起  
**状态：** M1 最小首页/阅读/文件打开已实现，等待真机

## M1 已验证

- Compose 首页 + SAF 打开文件
- AndroidView 承载 `ReaderSurfaceView`
- 顶部控制栏：返回、标题、页码、日夜
- M1d：进入阅读器隐藏三键导航栏，底部上滑由系统临时呼出，退出恢复
- M2b：设置对话框（主题/字号/行距/边距/亮度/编码）
- 首页展示 QuickJS 示例主题和命令结果
- 设置页、最近阅读、命令面板留到 M2/M5

## 目的

提供最小但完整的用户界面：打开书、继续阅读、阅读控制层、设置、插件管理。正文热路径交给 `reader-engine` 的自定义 View。

## 页面/状态

- 首页：打开文件、最近阅读、继续阅读
- 阅读器：正文、点击区域、顶部/底部控制层、进度
- 设置：主题、亮度、字号、行距、边距、翻页模式
- 插件管理：安装、启用/禁用、能力说明、卸载、安全模式
- 命令面板：搜索并执行内置/插件命令

首版不引入复杂导航库；使用简单的 sealed screen state。

## 技术约定

- Compose 负责壳层、设置和声明式面板
- 正文使用 `AndroidView` 承载 `ReaderSurfaceView`
- 主题 token 由内核/主题插件提供，UI 与阅读引擎共享
- 不在 Compose 重组中做解析/排版
- 所有按钮有 contentDescription；支持系统字体缩放

## 首版体验底线

- 打开文件路径清晰
- 返回键先关控制层再退出
- 进度在后台/旋转后恢复
- 无网络权限，不出现广告/账号入口
- 插件错误不阻塞阅读

## 测试

- Compose UI 测试：设置、插件列表、控制层
- 旋转/分屏/深色模式
- 低内存/进程重建
- 无障碍基本检查

## 退出标准

- M1：能打开 TXT、翻页、显示插件主题
- M2：设置/进度/日夜/亮度可用
- M5：四种翻页和命令面板可用
