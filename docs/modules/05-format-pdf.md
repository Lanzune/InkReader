# 模块 05：PDF 格式

**代码：** `formats/pdf`  
**阶段：** M4  
**状态：** 未开始

## 目的

使用系统 `android.graphics.pdf.PdfRenderer` 显示 PDF 页面，支持适配宽度、缩放、页码和夜间降亮，保持 APK 体积最小。

## 输入/输出

- 输入：可 seekable 的 `ParcelFileDescriptor`
- 输出：`BookDocument`（FixedPage）+ 页面位图/页码
- 不提取文本，不重排

## 首版范围

- 页面渲染、上一页/下一页
- 双指缩放、双击适配宽度
- 页码、缩放状态
- 夜间降亮（可选反色）
- 非 seekable 源临时复制并在关闭时删除

## 不支持

- 文本选择/搜索/复制
- 表单、批注、编辑
- PDF 重排
- 加密 PDF 的完整兼容（按系统版本尽力）

## 性能与安全

- PDF 一次只打开一个页面，串行渲染
- 位图按屏幕尺寸采样，限制单页像素
- 缩放停止后再按新尺寸重渲染
- 释放 Page/Renderer/FD；低内存时释放非当前页
- 官方建议不可信 PDF 在隔离进程渲染；v1 同进程，风险记录在报告和 ADR

## 测试

- 文本型/扫描型/大页面/多页 PDF
- 非 seekable provider
- 加密/损坏/超大 PDF
- 缩放后帧率与内存
- 退出/旋转/后台恢复

## 退出标准

- 常见 PDF 可稳定显示和翻页
- 缩放不 OOM
- 错误文件有可行动提示
- 关闭后无 FD/位图泄漏
