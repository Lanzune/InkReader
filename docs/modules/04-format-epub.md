# 模块 04：EPUB 格式

**代码：** `formats/epub`  
**阶段：** M3a
**状态：** 文本基线已真机验证；图片/CSS 待 M3b

## 目的

解析小说/读物类 EPUB 2/3 的重排内容，产出阅读引擎可用的块模型，并给出目录、封面和元数据。

## 处理链路

```text
ZIP 容器
→ META-INF/container.xml
→ OPF（metadata / manifest / spine）
→ NAV 或 NCX 目录
→ XHTML 内容文档
→ 受控 CSS 子集
→ 块模型 + 图片/链接
→ BookDocument
```

## 支持范围

- EPUB 2.0 / 3.x 重排内容
- 段落、标题、列表、引用、图片、基础强调、内部链接、脚注跳转
- 目录、封面、title/creator/language
- 基础 CSS：字体粗细/斜体、对齐、缩进、行高、受限字号、图片宽度

## 不支持

- DRM
- 固定版式 EPUB（后续兼容插件）
- 脚本、iframe、object、音视频
- MathML、复杂 SVG、浮动/定位/网格布局
- 远程资源

## 安全

- ZIP 路径穿越防护
- 压缩比/总解压大小/条目数/XML 深度限制
- XML 外部实体禁用
- 图片像素/解码内存上限
- 只允许容器内资源

## 测试语料

- EPUB 2 与 EPUB 3
- 中英文、多级目录、脚注、图片、封面
- 无 NCX/无 NAV、损坏 OPF、错误路径
- 固定版式/DRM 样本按“明确拒绝”验收

## 退出标准

- 语料库 ≥95% 可打开
- 不丢字、不重页、目录可跳转
- 封面/元数据正确
- 不支持的书显示明确提示而不是崩溃
