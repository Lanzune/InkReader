# 模块 01：QuickJS 插件宿主

**代码：** `plugin-host-quickjs`
**阶段：** M6a
**状态：** manifest 校验、能力白名单、2s 超时、启停已真机验证

## 当前实现（M1）

- 依赖 `io.github.dokar3:quickjs-kt:1.0.15`
- 从 APK assets 加载 `sample-theme.js`
- 执行脚本，读取一个主题和一个命令结果
- 失败不阻塞应用：首页显示插件错误，内置阅读仍可用
- QuickJS 在应用进程内运行；独立进程、`.inkp` 安装、权限/配额在 M6/v1.1

1.0.16 的 AAR metadata 要求 compileSdk 37 + AGP 9.1；当前项目使用 compileSdk 36 + AGP 8.13.2，因此暂锁 1.0.15。工具链升级后再评估。

## 目的

让主题、命令、声明式面板、设置和轻量规则可以在不重新编译主 APK 的情况下接入，同时不把任意 DEX/native 代码加载进主应用。

## 首版支持

- `.inkp` 包：`manifest.json` + `main.js` + 资源
- 主题、命令、面板、设置、TXT 章节规则
- 能力白名单和用户授权
- 单插件独立运行时
- 超时、内存、存储、日志上限
- 禁用/安全模式/卸载

## 不支持

- 页面渲染热路径/自定义 Canvas
- 任意 Android API、文件路径、网络
- DEX、JAR、`.so`
- 远程安装和自动更新

## 生命周期

```text
导入 → 校验 manifest/大小/路径 → 用户授权 → 安装私有目录
→ 激活 QuickJS → 注册贡献 → 运行命令/事件
→ 异常/超时 → 禁用/隔离 → 安全模式 → 重试/卸载
```

## 资源限制（首版默认）

| 项 | 限制 |
|---|---|
| 包总大小 | ≤5 MB |
| 单 JS | ≤1 MB |
| 运行时内存 | 16 MB |
| 激活 | ≤2 s |
| UI 钩子 | ≤50 ms |
| 用户命令 | ≤2 s |
| 私有存储 | 5 MB |

## 实现顺序

1. manifest schema + 校验
2. 运行时启动/关闭
3. `commands.register` + `themes.register`
4. 能力读取（reader state、settings、storage）
5. 事件（page.changed 等低频事件）
6. 错误/超时/禁用/安全模式
7. 示例主题插件、示例命令插件

## 安全边界

QuickJS 沙箱是可靠性和误操作边界，不是绝对安全边界。首版运行在专用线程；v1.1 迁移独立进程。插件只能通过能力接口访问宿主数据，不能获得 Android 对象。

## 测试

- 非法/超大/路径穿越的 manifest/zip
- 死循环、内存分配、超时命令
- 版本不匹配、未知能力
- 插件崩溃后主阅读链路继续
- 安装/启用/禁用/卸载后无残留

## 退出标准

- 主题插件能改变阅读背景/正文颜色
- 命令插件能读取当前进度并显示
- 插件超时不导致 App 崩溃
- 用户可以在 UI 中禁用插件并恢复内置主题
