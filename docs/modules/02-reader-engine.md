# 模块 02：阅读引擎

**代码：** `reader-engine`  
**阶段：** M1（最小）/ M2–M5（完整）  
**状态：** 未开始

## 目的

把格式插件产出的只读文档模型排版成页面，绘制到屏幕，并处理翻页、定位和主题。阅读引擎不直接读取文件，不依赖具体格式。

## 输入/输出

- 输入：`BookDocument`（Reflowable / FixedPage）、`Locator`、`ReaderTheme`、视口尺寸
- 输出：页面切片、绘制指令、新的 `Locator`、可渲染位图/Canvas

## 关键设计

- 文本使用 `StaticLayout` 做行级测量，按块/行装入页面。
- 当前章节和相邻章节按优先级布局；不一次布局整本书。
- `ReaderSurfaceView` 使用 Canvas 绘制，不在 `onDraw` 分配对象或读文件。
- 当前页/相邻页可预渲染为位图供翻页动画使用。
- 主题是 token（颜色、字体、字号、行距、边距），由主题插件贡献。
- 页面切换：滑动、覆盖、淡入、简化折页；低端机可降级。

## M1 最小范围

- 固定宽度分页
- 上一页/下一页/左右滑动
- 一个内置明/暗主题
- 页码/进度回调
- 不做折页、不做复杂排版

## M2–M5 完整范围

- 字号/行距/边距/对齐
- 图片按宽度缩放、低内存释放
- Locator 恢复与旋转重排
- 覆盖/淡入/折页
- 页眉页脚/章节标题/进度
- 无障碍基础语义

## 不负责

- 文件访问
- EPUB/PDF 解析
- 插件安装
- 主题编辑 UI

## 测试

- 不同字号/行距/屏幕尺寸不丢字、不重页
- 旋转/分屏后定位到最近字符
- 超长章节/大图片不 OOM
- 页面切换帧耗时
- 低内存回调释放资源

## 退出标准

- M1：TXT 能稳定翻页，60 fps 基本达标
- M2：进度恢复、日夜/亮度、图片可用
- M5：四种翻页模式可切换，低端机有降级路径
