# ADR-0003：首版自研轻量 EPUB 重排引擎

**状态：** Accepted  
**日期：** 2026-11-05

## 背景

EPUB 是首版核心格式。Readium 功能完整但依赖/内存较大，WebView 兼容性最好但和轻量、缓存、主题统一冲突。

## 决策

- 自研面向小说/读物类重排 EPUB 的轻量引擎。
- 处理 ZIP、container.xml、OPF、NAV/NCX、XHTML 块模型和受控 CSS 子集。
- 不支持固定版式、DRM、脚本、音视频、MathML/复杂 SVG。
- 复杂书未来作为可选兼容插件（WebView）处理，不进入核心。

## 替代方案

| 方案 | 不选原因 |
|---|---|
| Readium Kotlin Toolkit | 依赖多、体积/内存上升，导航器与自研分页/插件主题耦合 |
| 系统 WebView | 运行时内存、缓存、离线安全边界、主题统一困难 |
| 仅纯文本抽取 | 丢失目录/图片/基本排版，体验不足 |

## 后果

- 对小说类 EPUB 体验好、体积小、主题可控。
- 对复杂 CSS/固定版式兼容性有限，必须明确告知用户。
- 需要维护 EPUB 语料库和解析器安全限制。
- EPUB 解析工作量是 M3 的主要风险。

## 验证

- 20–30 本 EPUB 语料，≥95% 可打开。
- 不丢字、不重页、目录/封面/图片可用。
- 固定版式/DRM 显示明确不支持，不崩溃。
