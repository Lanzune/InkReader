# ADR-0005：主 APK 不声明 INTERNET 权限

**状态：** Accepted  
**日期：** 2026-11-05

## 背景

用户不需要远程传书、账号、广告或在线书源。网络权限会扩大隐私风险，也会让“无广告、本地优先”的承诺变得不可验证。

## 决策

- 主 APK 的 manifest 不声明 `android.permission.INTERNET`。
- 不集成广告、统计、账号、崩溃上报 SDK。
- EPUB/HTML/Markdown 的远程资源一律阻断。
- 插件默认无网络能力。
- 版本更新由用户手动安装 APK，不做检查更新请求。

## 后果

- 从系统层面保证应用无法直接联网。
- 无法提供在线书源、云同步、远程插件安装（即使未来需要，也要重新评估安全模型）。
- 部分依赖若隐式需要网络，必须移除或证明不触发。
- 插件生态只能本地安装，适合个人/小范围使用。

## 验证

- M0 起每次构建检查 manifest 无 INTERNET。
- 集成测试扫描所有依赖，确认无网络初始化。
- 发布前用 APK Analyzer 复核。
