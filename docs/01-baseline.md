# 基线定义

本项目把“基线”分三层，避免把“能启动”误认为“能交付”。

## B0 — Walking Skeleton（可行走骨架）

**目标：** 证明插件内核 + 阅读主链路可以同时成立。  
**阶段：** M1，约 2–3 周。  
**不是：** 可发布版本。

必须做到：

- 一个可安装的 debug APK
- 能打开一个本地 TXT 文件并分页显示
- 左右滑动翻页，至少一个内置主题
- 一个 QuickJS 主题插件能改变背景/文字颜色
- 一个 QuickJS 命令能显示当前进度
- 插件可禁用；插件异常不导致阅读器退出
- 无 `INTERNET` 权限
- 有最基本的 JVM 单元测试和构建体积记录

B0 的验收重点不是功能多，而是：**内核边界、插件边界、阅读热路径三者能接上。**

## B1 — Alpha Baseline（可日常试用）

**目标：** 形成一个“自己的书能读”的完整基线。  
**阶段：** M2–M4。  
**不是：** 功能齐全的 v1.0。

必须做到：

- 本地打开 TXT、EPUB 2/3 重排内容、PDF
- 滚动/分页阅读，进度自动保存和恢复
- 最近阅读列表
- 明/暗/跟随系统、亮度、字号、行距、边距
- 滑动翻页 + 覆盖/淡入
- TXT 编码探测和章节识别
- EPUB 目录、封面、图片、基础样式
- PDF 页面渲染、缩放、页码、夜间降亮
- 插件宿主可安装/禁用/安全模式
- 不缓存正文和页面；封面缓存有上限

B1 的验收重点：**没有插件也能完成一次完整阅读。**

## v1.0 — Release Baseline（可发布）

**目标：** 可交付的稳定版本。  
**阶段：** M5–M7。

在 B1 上增加：

- HTML/Markdown 单文件阅读
- 简化仿真折页，低端机自动降级
- 完整的插件 manifest、能力授权、版本协商
- 示例主题插件 + 示例命令插件 + 插件开发文档
- 性能、体积、16 KB 对齐、安全测试通过
- 签名 APK、校验值、发布说明、许可证清单
- 通过项目所有者的真机验收清单

## 基线不包含

- CBZ/FB2（v1.1）
- EPUB 固定版式兼容插件
- PDF 文本搜索/选择
- 原生插件 APK 宿主（v2）
- 云同步、账号、在线书源

## 基线预算

| 项目 | B1 | v1.0 |
|---|---|---|
| arm64 release APK | ≤14 MB | ≤12 MB |
| 冷启动 | ≤1.2 s | ≤1.0 s |
| 翻页 | 可感知流畅 | 60 fps，低端机有降级 |
| 缓存 | 仅封面 ≤16 MB | 仅封面 ≤16 MB |
| 权限 | 无危险权限、无网络 | 无危险权限、无网络 |

## 基线变更

任何把 v1.0 功能提前到 B0/B1 的提议，都必须说明：

1. 它是否影响插件边界；
2. 它增加多少体积/内存；
3. 它是否可以用临时实现替代；
4. 它是否值得推迟下一个格式或稳定性工作。
