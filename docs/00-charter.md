# 项目章程

**项目：** InkReader（内部代号）  
**状态：** M0 进行中  
**日期：** 2026-11-05

## 1. 一句话定义

一个轻量、本地优先、无广告、可插件扩展的 Android 电子书阅读器：**默认轻，按需重；小内核，厚插件；装得少、跑得稳、卸得掉。**

## 2. 目标用户与场景

- 主要用户：希望在手机上安静阅读本地书籍、不希望被广告和账号体系打扰的人。
- 核心场景：打开本地 EPUB/TXT/PDF，继续上次进度，调整亮度/字号/翻页方式；需要新能力时再安装插件。
- 非目标用户：需要在线书城、社交、云同步、听书、笔记生态的用户。

## 3. 产品原则

1. **基线完整**：不靠插件才能完成基本阅读。
2. **复杂度可撤退**：用户不安装插件，就不承担插件的体积和内存。
3. **内核不可协商**：文件访问、会话状态、权限、存储一致性、版本协商留在 PageKernel。
4. **插件不是后门**：第三方脚本没有网络、任意文件、Android Context 或任意 UI 注入。
5. **本地优先**：主 APK 不声明 `INTERNET`；不集成广告、统计和账号。
6. **命令行可验证**：能在 JVM/构建层验证的，不依赖人工点按；必须真机验证的，明确交给项目所有者。
7. **先证明，再扩展**：每个阶段有可运行产物和退出标准，不并行堆未验证功能。

## 4. 首版边界

**v1.0 计划包含**

- 本地打开 EPUB 2/3 重排内容、TXT、PDF、HTML、Markdown
- 分页阅读、进度恢复、最近阅读
- 明/暗/跟随系统主题、亮度、字号/行距/边距
- 滑动、覆盖、淡入、简化仿真折页
- 插件内核：主题、命令、声明式面板、设置、TXT 章节规则
- QuickJS 脚本宿主、能力授权、安全模式
- 无网络、无广告、低缓存

**明确不做**

- DRM 绕过、固定版式 EPUB、脚本化 EPUB、音视频
- PDF 重排、编辑、批注、表单
- MOBI/AZW3、DOCX/RTF、DJVU（后续插件）
- TTS、词典、笔记、AI 摘要、云同步、账号、书城
- 主应用内加载 DEX 或任意原生插件
- 插件市场、远程安装、自动更新

## 5. 成功标准

| 维度 | 标准 |
|---|---|
| 可用 | 用户能打开一本常见 EPUB/TXT/PDF，顺畅阅读并恢复进度 |
| 轻量 | arm64 release APK 目标 ≤12 MB；无 WebView/PDFium/Readium |
| 流畅 | 中端机翻页稳定 60 fps；冷启动目标 ≤1 s |
| 干净 | 主 APK 无 `INTERNET`；仅封面缩略图缓存；无广告/统计 |
| 可扩展 | 一个第三方主题插件和一个命令插件可以通过文件安装、运行、禁用 |
| 可维护 | 模块依赖单向；公开 API 有版本和契约测试；每个模块有文档 |
| 可控 | 基线体积、运行时内存、缓存、插件存储都有预算和上限 |

## 6. 关键决策

- Kotlin 原生 + Compose 壳层 + 自定义 Canvas 阅读视图
- PageKernel 可信内核；内置功能也走插件接口
- 第三方插件用 QuickJS 脚本，不加载 DEX
- EPUB 自研轻量重排引擎；PDF 用系统 `PdfRenderer`
- 主 APK 无 `INTERNET`；文件通过 SAF 读取
- 原生插件通道预留为 v2 的独立 APK + AIDL 服务

详细论证见 [技术方案与实施报告](reports/ebook-reader-technical-report.zh-CN.md)。

## 7. 约束与假设

- 目标 Android 8.0+（`minSdk 26`），`targetSdk 36`
- 首发以直接安装签名 APK 为主；是否上架 Google Play 待定
- 1 名主要开发者 + 项目所有者负责真机验收
- 当前机器有 Android SDK、NDK、Android Studio、JDK 21 和 Gradle 8.14 缓存；仍需项目级配置
- 当前没有模拟器系统镜像和 AVD，运行时验证优先使用真实手机
- 当前没有 GitHub 远端和正式签名密钥，不阻塞 M0

## 8. 变更规则

- 新增格式/插件类型/公开 API：先写 ADR 或规格，再实现。
- 修改 v1 范围：更新本文件、路线图和阶段计划。
- 体积/性能目标变更：必须附测量结果，不能凭感觉放宽。
