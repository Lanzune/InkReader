# M9：百分比内核与插件化页码

**目标：** 阅读进度以字符百分比为内核，全书页码作为第一个可选插件，并完成 0.9.0 发布收尾。

## 阶段

| 阶段 | 内容 | 状态 |
|---|---|---|
| M9.1 | 百分比内核、关闭默认全书分页、总字符估算 | ✅ 0.9.0 |
| M9.2 | `progress.contribute`、`reader.pagination`、页码插件、运行时 | ✅ 0.9.0 |
| M9.3 | 多插件安装管理、发布检查、低端机后续验收 | ⏳ 下一步 |

## 设计

- 内核只计算 `charOffset / totalChars`
- 页码插件启用时才加载/构建 PageIndex
- 插件异常、超时、关闭时回退百分比
- 百分比不依赖布局；页码依赖布局签名
- 大书安全模式不做全书页索引，只做字符百分比

## 验收

- 插件关闭：打开 300 ms 内出现百分比，之后不出现页码
- 插件开启：有页索引时立即显示页码，无索引时先百分比后页码
- 关闭插件后页分页任务取消
- 页索引不阻塞打开
- 插件契约有文档、示例和测试
- release 构建、签名、权限、体积检查通过

## 已知边界

- 页码插件目前是内置第一方插件，不是 `.inkp` 安装项
- 没有页索引的新书，页码会晚于百分比出现
- 页码会随字号/行距/屏幕变化，百分比不会
- PDF 仍使用固定页页码
