# M8：打开速度

**目标：** 小书首屏 ≤300 ms，大书首屏 ≤1 s，全部格式可交互。

## 阶段

| 阶段 | 内容 | 状态 |
|---|---|---|
| M8a | 测量脚本、并行 EPUB 解析、首屏局部排版、后台富文本/分页、内存缓存 | ✅ 0.8.0 |
| M8a.1 | 页面图片预加载，去掉绘制时解码/弹图 | ✅ 0.8.1 真机 |
| M8b | EPUB `openPreview`：ZipFile 随机读 + 前 8 章 + 后台全量 | ✅ 0.8.2 |
| M8b.1 | 目标章定位、content URI 本地缓存、章节索引、字符预算、图片位图复用 | ✅ 0.8.3 首屏 0.21s / 续读 0.75s |
| M8c | 增量章节追加、TXT/HTML/MD 流式、PDF 基准、持久页索引 | ⏳ 待开始 |
| M8d | 低端机、全格式验收 | ⏳ 待开始 |

## M8a 结果

- 基线：约 8.4 s
- 首屏局部排版：主线程不再构建全书 `StaticLayout`
- 并行解析：约 2.4 s → 1.9 s
- 富文本后台化：约 1.1 s 移出首屏主线程
- 同书二次打开：约 2.5 s（含 UI 脚本开销）
- 首屏实测约 2.2 s（截图）

仍未达标，M8b 必须继续做章节级懒加载和持久索引。

## M8b.1 结果

- `content://` EPUB 一次性缓存成本地文件，预览才真正生效
- 章节起点索引持久化，从任意进度继续都能预览目标章
- 预览按目标章 + 约 8 万字窗口读取，不再固定前 8 章
- XHTML 预览只解析一次，章节解析约减半
- 当前 12.5 MB EPUB：
  - 第 1 页图文就绪约 **0.21 s**
  - 末尾“译后记”继续阅读约 **0.75 s**
  - 冷启动 Activity 142 ms
- 完整解析仍在后台进行（约 1.6–2.1 s），完成后替换预览
- 详见 [M8b.1 记录](../quality/2026-11-08-m8b1-open.md)

## 验收

- 小 EPUB ≤300 ms
- 当前 12 MB EPUB 首屏 ≤1 s
- 100 MB EPUB 不 OOM
- TXT/HTML/MD/PDF 对照
- 无 ANR、无主线程 >32 ms 长任务
