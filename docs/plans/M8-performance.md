# M8：打开速度

**目标：** 小书首屏 ≤300 ms，大书首屏 ≤1 s，全部格式可交互。

## 阶段

| 阶段 | 内容 | 状态 |
|---|---|---|
| M8a | 测量脚本、并行 EPUB 解析、首屏局部排版、后台富文本/分页、内存缓存 | ✅ 0.8.0 |
| M8a.1 | 页面图片预加载，去掉绘制时解码/弹图 | ✅ 0.8.1 真机 |
| M8b | EPUB `openPreview`：ZipFile 随机读 + 前 8 章 + 后台全量 | ✅ 0.8.2 |
| M8b.1 | 目标章定位、content URI 本地缓存、章节索引、字符预算、图片位图复用 | ✅ 0.8.3 首屏 0.21s / 续读 0.75s |
| M8c.1 | 持久页索引、布局签名、首帧全书页码 | ✅ 0.8.4 打开即 10/4145 |
| M8c.2 | TXT/HTML/MD 前缀首屏、PDF 基准、初始 URI | ✅ 0.8.4 |
| M8c.3 | 预览按需切换完整书，目录/接近末尾才重排 | ✅ 0.8.4 |
| M8d | 大书完全懒加载、低端机、全格式验收 | ⏳ 待开始 |

## M8a 结果

- 基线：约 8.4 s
- 首屏局部排版：主线程不再构建全书 `StaticLayout`
- 并行解析：约 2.4 s → 1.9 s
- 富文本后台化：约 1.1 s 移出首屏主线程
- 同书二次打开：约 2.5 s（含 UI 脚本开销）
- 首屏实测约 2.2 s（截图）

仍未达标，M8b 必须继续做章节级懒加载和持久索引。

## M8b.1 结果

- `content://` EPUB 一次性缓存成本地文件，预览才真正生效
- 章节起点索引持久化，从任意进度继续都能预览目标章
- 预览按目标章 + 约 8 万字窗口读取，不再固定前 8 章
- XHTML 预览只解析一次，章节解析约减半
- 当前 12.5 MB EPUB：
  - 第 1 页图文就绪约 **0.21 s**
  - 末尾“译后记”继续阅读约 **0.75 s**
  - 冷启动 Activity 142 ms
- 完整解析仍在后台进行（约 1.6–2.1 s），完成后替换预览
- 详见 [M8b.1 记录](../quality/2026-11-08-m8b1-open.md)

## M8c.1 结果

- 完整页索引按布局签名持久化，4145 页约 16.6 KB
- 打开后约 120 ms 顶栏直接显示 `10/4145`
- 未等完整布局即可按索引左右翻页，显示 `11/4145`
- 完整布局完成后页码不跳变
- 改字号/行距/旋转会生成新签名，不会误用旧索引
- 首次打开且无索引时仍需先建立索引
- 详见 [M8c.1 记录](../quality/2026-11-08-m8c-page-index.md)

## M8c.2 结果

- TXT/HTML/Markdown 只读前 256 KB 建立首屏，不复制整本文件
- 7.7 MB TXT：首次约 250 ms 显示正文；再次打开立即 `1/7637`
- 115 KB Markdown：约 250 ms 显示正文
- 99 KB PDF：冷启动 Activity 186 ms，500 ms 内显示 1/2 页
- 支持通过外部 `VIEW` Intent 传入文件 URI
- 详见 [M8c.2 记录](../quality/2026-11-08-m8c-text-pdf.md)

## M8c.3 结果

- 完整解析完成后不再立即替换阅读页
- 预览会保持到接近窗口末尾（约 6,000 字）或用户点击“目录”
- 切换时保持当前字符偏移，页码不跳变
- 12.5 MB EPUB 第 10/4145 页：打开 150 ms，切换后仍为 10/4145
- 100 MB 级完全懒加载留到 M8d
- 详见 [M8c.3 记录](../quality/2026-11-08-m8c-on-demand.md)

## 验收

- 小 EPUB ≤300 ms
- 当前 12 MB EPUB 首屏 ≤1 s
- 100 MB EPUB 不 OOM
- TXT/HTML/MD/PDF 对照
- 无 ANR、无主线程 >32 ms 长任务
