# M6：插件 SDK 与安全

**目标：** 把 QuickJS 示例插件扩展为可校验、可安装、可启停的插件基线。  
**前置：** M5 完成。

## 拆分

| 子阶段 | 内容 | 状态 |
|---|---|---|
| M6a | manifest 校验、能力白名单、2s 超时、启停 | ✅ 真机 |
| M6b | `.inkp` 导入/安装、路径/大小限制、卸载 | ✅ 真机 |
| M6c | 插件开发文档、命令面板接入、合并标签 | ⏳ 待开始 |

## M6 退出标准

- manifest 非法/未知能力/路径穿越直接拒绝
- `.inkp` 只安装到应用私有目录
- 插件启停、卸载、回退内置主题
- 插件异常/超时不影响主阅读链
- 文档说明能力边界和信任模型
- 项目所有者验收

## 后续

- 插件进程隔离（v1.1）
- 多插件并存/权限授权页
- 插件命令动态注册
