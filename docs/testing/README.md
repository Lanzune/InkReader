# 测试策略

## 测试层级

| 层级 | 工具 | 执行者 | 主要内容 |
|---|---|---|---|
| L0 单元 | JUnit | 开发 | 解析、编码、Locator、manifest、分页算法 |
| L1 集成 | Robolectric / 临时文件 | 开发 | 文件源、会话、插件生命周期、错误路径 |
| L2 构建 | Gradle / APK Analyzer / lint | 开发 | assemble、权限、体积、16 KB |
| L3 真机 | 实际 APK | 项目所有者 | SAF、手势、字体、PDF、厂商兼容 |
| L4 回归/性能 | Macrobenchmark/Perfetto | 双方 | 启动、帧率、内存、格式语料 |

## 格式语料

- TXT：UTF-8/UTF-16/GB18030/Big5，大文件，无章节
- EPUB 2/3：中英文、图片、脚注、目录、损坏/固定版式
- PDF：文本型、扫描型、大页面、加密/损坏
- HTML/Markdown：脚本、远程资源、缺失资源

样本本身不入库；记录来源、哈希、预期行为和是否通过。

## 设备矩阵

| 设备 | 用途 |
|---|---|
| 主力 Android 手机 | 全流程 |
| 低端/旧 Android（8–10） | 内存、帧率、兼容 |
| 高刷新/新 Android（15–16） | 16 KB、现代行为 |
| 模拟器 | 仅作为无设备时的构建/冒烟补充 |

## 真机反馈格式

项目所有者回传：

- 机型、Android 版本、APK commit/版本
- 操作步骤与预期
- 截图/录屏
- 相关 `logcat` 崩溃
- 是否阻塞下一阶段

## 不做的测试

- 不声称在未运行的设备上通过
- 不用单个 EPUB/TXT 代表格式兼容
- 不用 debug 构建的帧率代表 release
