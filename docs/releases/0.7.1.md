# InkReader 0.7.1 发布说明

## 新增

- TXT / EPUB / PDF / HTML / Markdown 阅读
- EPUB 图片、样式、脚注、内部链接
- PDF 翻页、缩放、夜间
- Markdown 标题目录、强调、内部链接
- 翻页滑动动画和开关
- 阅读器命令面板
- QuickJS 插件 manifest、`.inkp` 安装/卸载/启停

## 0.7.1 新增

- 阅读数据导出/导入：
  - 阅读进度
  - 阅读设置
  - 插件启停状态
  - 当前书籍副本
- 正式 release 签名（RSA 4096）
- R8 release 构建，APK 约 4.32 MiB

## 安全

- 无 `INTERNET` 权限
- 插件禁止 DEX/JAR/SO/APK 和路径穿越
- 插件包 5 MB、脚本 1 MB、激活 2 s 限制
- 正式签名私钥不进入 Git，需离线备份

## 已知限制

- 插件与主应用同进程，不是进程隔离
- 只支持一个已安装插件
- 安装即信任，无签名校验
- PDF 无文本选择/搜索
- HTML/Markdown 不加载远程资源
- 备份只包含最近阅读的一本书

- DN：`CN=InkReader, OU=Personal, O=InkReader, C=CN`
- 证书 SHA-256：`07E08D20E75B60FA1FB749AC3CA5FCDE23406DEB09B22F5CD387CF13D2D7E22B`
- APK SHA-256：`530DEDA5101C8EF410812D07DD3F35CC774B0992A969500650F10F5478E973B1`

## 安装

- 正式包不能覆盖 debug 版
- 卸载前先导出阅读数据
- 安装后通过“导入阅读数据”恢复
