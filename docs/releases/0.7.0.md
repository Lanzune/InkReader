# InkReader 0.7.0 发布说明（草稿）

## 新增

- TXT / EPUB / PDF / HTML / Markdown 阅读
- EPUB 图片、样式、脚注、内部链接
- PDF 翻页、缩放、夜间
- Markdown 标题目录、强调、内部链接
- 翻页滑动动画和开关
- 阅读器命令面板
- QuickJS 插件：
  - manifest/能力校验
  - `.inkp` 安装/卸载
  - 插件启停

## 改进

- 翻页快照位图复用，减少每页分配
- 阅读设置持久化
- 沉浸式导航栏
- 首页可滚动

## 安全

- 无 `INTERNET` 权限
- 插件禁止 DEX/JAR/SO/APK 和路径穿越
- 插件包 5 MB、脚本 1 MB、激活 2 s 限制

## 已知限制

- 插件与主应用同进程，不是进程隔离
- 只支持一个已安装插件
- 安装即信任，无签名校验
- PDF 无文本选择/搜索
- HTML/Markdown 不加载远程资源

## 签名

正式包需使用 release keystore；`m7a` 构建使用 debug 证书，仅测试。
