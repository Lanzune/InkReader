# InkReader 0.7.2 发布说明

## 许可证

InkReader 从 0.7.2 起采用 **AGPL-3.0-only**。

- 完整许可证：`LICENSE`
- 第三方组件：`NOTICE`
- 贡献规则：`CONTRIBUTING.md`
- 商标：`TRADEMARK.md`

修改后分发必须提供完整对应源码；修改版作为网络服务提供时必须向用户提供源码。私人使用且不分发不强制公开。

## 新增

- 首页“关于 / 许可证”对话框
- 应用内 `assets/LICENSE.txt`
- 应用内 `assets/NOTICE.txt`
- 源文件 SPDX 许可证头

## 功能

- TXT / EPUB / PDF / HTML / Markdown
- EPUB 图片、样式、脚注、内部链接
- PDF 翻页、缩放、夜间
- Markdown 标题、强调、内部链接
- 翻页动画、命令面板
- QuickJS 插件 manifest、`.inkp` 安装/卸载/启停
- 阅读数据导出/导入

## 安全

- 无 `INTERNET`
- 插件禁止 DEX/JAR/SO/APK 和路径穿越
- 正式 release 签名，私钥不入库

## 已知限制

- 插件与主应用同进程
- 单插件
- PDF 无文本选择/搜索
- HTML/Markdown 不加载远程资源
- 备份只包含最近阅读的一本书
