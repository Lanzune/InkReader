# M2b7 每页独立布局渲染（2026-11-06）

## 为什么前面几次仍会裁切

之前一直用**整本书共用的一个 `StaticLayout`**，分页后只通过 `clipRect` 截取某一页：

- 页首会把上一页最后一行的 descender 一起画进裁剪区；
- `includePad` 只作用于整本书布局的第一行/最后一行，不作用于每一页；
- 无论怎么调 clip/inset，都可能出现页首或页尾半行被切。

## 最终修复

绘制时不再从整本书布局裁剪，而是**为当前页单独创建一个 `StaticLayout`**：

1. 先用整本书布局计算分页行号和页首字符偏移；
2. 取当前页的字符区间 `[startChar, nextPageStartChar)`；
3. 用这段文本单独构建当前页布局，`setIncludePad(true)`；
4. 页布局从 `contentTop + 48dp` 开始绘制，只画这一页自己的文本。

因此：

- 不会把上一页最后一行画进页首；
- 页首有 `includePad` + 48dp 安全区；
- 页尾只画本页文本，下方仍有 56dp + 24dp 安全区；
- 裁剪只影响本页，不再依赖整书布局的行边界。
