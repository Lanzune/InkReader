# M3b1 EPUB 图片（2026-11-07）

## 范围

- EPUB `<img>` 识别，保留为文本占位符并记录字符偏移
- 图片资源从 ZIP 取出，放入 `BookDocument.resources`
- App 用 `ImageSpan` 渲染图片，按页面宽度/高度等比缩放并居中
- `LazyEpubDrawable`：打开时只读图片尺寸，页面真正绘制时才解码
- TXT/EPUB 共用阅读器；目录、进度、字号/行距/亮度继续有效

使用手机上的真实 EPUB《拿破仑大帝（全2册）》：
