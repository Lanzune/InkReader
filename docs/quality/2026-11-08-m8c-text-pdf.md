# M8c.2 TXT / Markdown 首屏与 PDF 基准（0.8.4）

## TXT / HTML / Markdown 前缀预览

`BookSource` 新增 `readPrefix(maxBytes)`：

- `ContentBookSource` 直接向 provider 读前 256 KB，不复制整本文件
- `FileBookSource` 只读文件前 256 KB
- 默认实现退回 `readAll()`，测试和 asset 源不需要改动

`TxtFormatProvider.openPreview()` 和 `HtmlMarkdownFormatProvider.openPreview()` 用前缀构建临时 `BookDocument`。阅读进度在预览范围内时立即进入阅读页；超出范围则退回完整解析。

完整解析仍在后台进行，完成后替换为全书文本；持久页索引继续提供完整页码。

## 真机结果

设备：OnePlus Ace 5，Android 16

### 7.7 MB TXT

- 首次打开约 250 ms 显示正文，顶栏 `1/…`
- 完整解析后 `1/7637`
- 再次打开约 250 ms 直接显示 `1/7637`
- 章节标题首行和正文正常

### 115 KB Markdown

- 约 250 ms 显示正文，`1/128`
- 标题、正文正常

### 99 KB PDF（内置示例）

- 冷启动 Activity `am start -W`：186 ms
- 500 ms 内显示第 1/2 页和缩放控件
- PDF 走系统 `PdfRenderer`，没有额外解析

## 限制

- 前缀预览只覆盖文件开头；保存位置在 256 KB 之后时会退回完整解析
- 前缀按字节截断，可能切在多字节字符中间；解码器会用替换字符收尾，不影响后续全文替换
- PDF 目前只验证了 2 页示例，没有大 PDF 样本
- 完整解析仍会读整个 TXT/Markdown 文件；真正的流式追加还未做
