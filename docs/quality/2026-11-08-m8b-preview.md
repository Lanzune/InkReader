# M8b EPUB 预览加载（0.8.2）

## 目标

打开时只读取元数据、目录和开头章节，让阅读器先出来，再在后台加载完整书。

## 实现

- `EpubFormatProvider.openPreview()`
  - 使用 `ZipFile` 随机读
  - 只读 `container.xml`、OPF、NAV/NCX
  - 只读前 8 个 spine 章节和这些章节引用的图片
  - 返回一份可立即阅读的 `BookDocument`
- `openUri()`：
  - 先尝试 preview；命中后立即进入阅读页
  - 同时后台执行完整解析
  - 完整结果写入进程内缓存，替换时不重新显示文字半成品
- 页面图片仍按 M8a.1 规则：
  - 完整页（文字 + 图片）就绪后才绘制

## 真机结果

当前 12.5 MB EPUB：

- 0.8.2 冷启动：约 **2.2 s** 首屏（仍高于 1 s）
- 0.8.1：约 4.0 s 完整页
- 预览没有先显示“无图文字页”
- 4.2 s 后仍显示同一页（完整内容索引更新）
- 暖启动仍约 2.5 s

## 仍未达标

- 首屏 2.2 s，目标 <1 s
- preview 只含前 8 章；目录/页数在完整解析后才完整
- 完整解析仍会读全 ZIP 和解析全部 XHTML
- TXT / HTML / Markdown 仍没有流式首屏
- 持久化索引未做

## 下一步

- 让 preview 覆盖目标阅读位置，而不是固定前 8 章
- 完整解析改为增量章节追加，不再整体替换
- EPUB 只解压当前章图片
- TXT/HTML/MD 流式解码与首屏
- 持久化页索引
