# M1d 沉浸式阅读修复（2026-11-06）

## 问题

项目所有者使用三键虚拟导航栏。阅读器底部被导航栏占据/遮挡，影响沉浸感。期望行为：

- 进入阅读器后隐藏导航栏
- 从屏幕底部上滑时临时呼出
- 离开阅读器后恢复导航栏

## 实现

使用 Android 标准沉浸式行为，不自行实现底部手势：

- `WindowInsetsControllerCompat`
- `hide(WindowInsetsCompat.Type.navigationBars())`
- `systemBarsBehavior = BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE`
- 进入阅读器时隐藏；`ON_RESUME` 再次隐藏
- 退出阅读器时 `show(navigationBars)` 并恢复默认行为

状态栏保留，不隐藏时间/电量；只处理底部导航栏。

## 真机验收

1. 打开 TXT，进入阅读器。
2. 确认底部三键导航栏消失，正文可使用底部空间。
3. 从屏幕底部上滑，确认导航栏临时出现，随后自动隐藏。
4. 点击中间区域显示/隐藏控制栏，确认仍流畅。
5. 返回首页，确认导航栏恢复。
6. 退到后台再回来，确认阅读器仍隐藏导航栏。
