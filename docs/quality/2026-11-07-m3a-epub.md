# M3a EPUB 文本基线（2026-11-07）

## 范围

- 新增 `formats/epub` Kotlin JVM 模块
- EPUB 2/3：ZIP → container.xml → OPF → NAV/NCX → XHTML
- 元数据：title/creator/language
- 目录映射：NAV/NCX 标题与字符偏移
- 正文转纯文本：段落/标题分行、实体解码、脚本/样式/iframe 剔除
- 安全：路径穿越拒绝、ZIP 条目/大小限制、XML DOCTYPE/外部实体禁用

## 现有阅读器复用

- `BookDocument.chapters` 仍是单章合并文本
- 目录通过 `TocEntry.charOffset` 跳转
- 进度、字号/行距/亮度、导航栏沉浸直接复用 M2
