# M8c.1 立即显示全书页码（0.8.4）

## 要求

> 阅读进度，比方说 10/4145，不是一打开书就有的，而是要加载一段时间后才出现。
> 希望一进来就能看到完整的整本书的阅读进度，而不是还要等待。

## 问题

页码依赖全书分页：

- `ReaderSurfaceView` 先局部排版当前页，页码只能显示 `1/…`
- 后台构建完整 `StaticLayout` 并扫描 4145 页，12.5 MB 书约 2.2–2.5 s
- 完整页索引完成后页码才变成 `10/4145`

所以“打开快”和“页码完整”之前是互斥的。

## 实现

### 持久页索引

`PageIndexStore` 把完整分页结果保存到 `filesDir/page-index/*.bin`：

- 内容：每页起始字符偏移的 `IntArray`
- 4145 页约 16.6 KB
- 原子写入，最多保留 20 个文件 / 2 MB
- 小窗口索引不能覆盖完整索引（只接受页数更多的结果）

### 布局签名

索引按布局签名隔离，只有下列值完全一致才会复用：

- 内容宽、分页可用高
- 字体像素大小、字号设置
- 行距倍数
- 索引格式版本

旋转屏幕、改字号、改行距都会得到新签名，不会误用旧页码；旧索引仍然保留，改回设置时可以立即复用。

### 首帧应用

- `ReaderSurfaceView.applyPageIndex(starts)` 在完整 `StaticLayout` 完成前设置页码映射
- `pageInfo()` 用二分查找得到当前字符偏移所在页，`pageCount` 直接使用完整索引长度
- 当前页直接按索引给出的页起止字符排版，不依赖 20 万字的整书布局
- 左右翻页也先走索引；索引页码和完整布局一致时不会跳变
- 完整布局完成后自动切回真实页表，并用真实页表刷新索引

### 保存时机

- 预览阶段 `pageIndexSaveEnabled = false`，不会把 110 页的窗口索引写成全书索引
- 完整书文本应用后，完整布局完成时保存 4145 页索引
- 页码索引和书籍章节索引分开存储

## 真机结果

设备：OnePlus Ace 5，Android 16  
书：12.5 MB EPUB，4145 页

| 时刻 | 结果 |
|---|---|
| 点击“继续阅读”后约 120 ms | 页面已显示，顶栏直接是 **10/4145** |
| 约 250 ms 内右翻一页 | 直接显示 **11/4145**，文字和两张插图完整 |
| 完整布局完成后 | 仍为 10/4145，不跳页 |

## 限制

- 一本书第一次打开、还没有索引时，仍然只能先显示百分比，等完整布局后建立索引；从第二次打开开始页码立即完整
- 页码索引依赖布局签名；改字号后的第一次打开会重新建立该字号的索引
- 完整布局仍是一次性构建，耗时约 2.2 s，但不再阻塞页码显示
