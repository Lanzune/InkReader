# M1c 修复记录（2026-11-06）

## 反馈来源

项目所有者真机验证 M1b 后反馈：

1. TXT 能打开，但中文乱码；
2. 点击中间区域显示/隐藏控制栏时卡顿明显；
3. 翻页可用，主题切换效果正常。

## 修复

### 编码探测

新增 `TxtDecoder`：

- BOM：UTF-8 / UTF-16LE / UTF-16BE
- 无 BOM 的明显 UTF-16 检测
- 严格 UTF-8 解码
- GB18030 与 Big5 严格解码 + 中文文本评分
- UTF-8 兜底

单元测试覆盖 UTF-8 BOM、GB18030、Big5、UTF-16LE BOM。

M2 仍会加入用户手动切换编码；M1c 先解决最常见的 GBK/GB18030 乱码。

### 控制栏卡顿

原因是控制栏显隐改变了阅读 View 的高度，触发整章 `StaticLayout` 重新分页。M1c 改为：

- 阅读 View 始终全屏、尺寸不变；
- 顶部控制栏改为覆盖层；
- 阅读内容顶部预留 88dp；
- 显隐只影响覆盖层，不重新分页。
