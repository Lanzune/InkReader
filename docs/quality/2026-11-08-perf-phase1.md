# Performance Phase 1（2026-11-08）

## 目标

先解决“打开全书必须等全部解析、全部排版、全部页索引”的问题，为后续章节懒加载铺路。

## 已完成

### EPUB 解析

- 章节 XHTML 并行解析（`parallelStream`）
- 保留原有顺序、目录、样式、图片、脚注、内部链接
- 大书解析从约 2.4 s 降到约 1.9 s（当前 12.5 MB 书）

### 阅读器排版

- 首次只排版当前页附近窗口，不再主线程构建全书 `StaticLayout`
- 首屏先显示当前页；完整页索引在后台构建
- 页数完成前显示 `1/…`，完成后恢复 `X/4145`
- 后台排版使用 `TextPaint` 副本，避免和绘制线程争用
- 翻页、上一页、目录跳转在完整索引前使用局部分页

### 富文本

- 样式/图片/链接的 `SpannableStringBuilder` 构建移到后台
- 首屏先用纯文本；富文本完成后再替换，保留字符位置
- 12000+ spans 的处理不再阻塞首屏

### 缓存

- 增加进程内最近一本书的 `BookDocument` 缓存
- 同一本书第二次打开跳过解析
- 缓存键包含 URI、大小、编码

### 工具

- 新增 `scripts/bench-open.ps1` / `.cmd`
- 输出 p50/p95、冷启动、CSV
- `benchmark/README.md`

## 实测

当前书：12.5 MB EPUB，50 个 XHTML，127 张图片，约 111 万字，4145 页。

阶段耗时（instrumented release）：

| 阶段 | 时间 |
|---|---|
| EPUB 读取/解压/解析（并行） | 约 1.9 s |
| 富文本构建（后台） | 约 0.96 s |
| 完整分页（后台） | 约 3.3–4.1 s |
| 首屏可见 | 约 2.2 s（截图确认） |

黑盒脚本（含 UI Automator 开销）：

| 模式 | 结果 |
|---|---|
| 0.7.2 基线 | 8.414 s |
| 0.8.0 首轮 | 5.03 s |
| 0.8.0 缓存命中 | 2.50 s（run2/3） |

结论：主线程不再被 2.6 s 全书排版阻塞；缓存命中后打开时间明显下降。**但首轮仍约 2 s，未达到 <1 s 目标。**
