# M5b 命令面板（2026-11-08）

## 范围

- 阅读器顶部新增“命令”入口
- 命令面板统一入口：
  - 打开目录
  - 阅读设置
  - 切换日间/夜间
  - 上一页/下一页
  - 显示当前页与 QuickJS 插件命令结果
- 设置入口从顶栏移入命令面板，避免顶栏拥挤
- 返回键在命令面板打开时先关闭面板

## 真机验证

Markdown 样书：

- 顶栏：返回 / 标题 / 页码 / 目录 / 命令
- 命令面板显示 1/2 页
- 插件命令：阅读进度 42%
- 上一页在首页禁用
- 设置/目录/日夜命令可用
