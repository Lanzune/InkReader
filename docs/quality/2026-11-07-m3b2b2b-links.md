# M3b2b2b EPUB 脚注/内部链接（2026-11-07）

## 范围

- 识别 `<a href="#id">`、`<a href="chapter.xhtml#id">`、`<a href="chapter.xhtml">`
- 识别 `<a id="...">` 锚点
- 链接字符区间写入 `Chapter.links`
- 目标解析为全书字符偏移：
  - 同章 `#id`
  - 跨章 `chapter.xhtml#id`
  - 无 fragment 的章节链接跳到章首
- App 用 `ReaderLinkSpan` 渲染紫色下划线
- ReaderSurfaceView 命中链接时优先跳转，不触发翻页

## 已知限制

- 外链/HTTP 链接不打开浏览器
- 非 `<a id>` 的锚点（如 `<span id>`）暂未收集
- 链接跳转后没有“返回原位置”栈
- 基于 class 的 CSS 对齐、首行缩进仍待做
