# 格式语料清单

> 样本本身不进入仓库。此目录只记录样本来源、哈希、预期行为与测试结果。

## 模板

```text
ID:
格式/版本:
来源:
SHA-256:
大小:
预期:
已知限制:
测试阶段:
结果:
备注:
```

## 最低覆盖

- EPUB 2：5 本
- EPUB 3：5 本
- 中文 TXT：5 个（UTF-8/GBK/GB18030/Big5/UTF-16）
- 英文 TXT：3 个
- 大文件 TXT：1 个 ≥100 MB
- PDF：文本型 3 个、扫描型 2 个、大页面 1 个
- HTML/Markdown：各 3 个
- 损坏/不支持样本：单独归类，不计入通过率

## 隐私

只记录哈希和来源，不提交书籍文件、封面或正文摘录。
