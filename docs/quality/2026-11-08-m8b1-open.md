# M8b.1 目标位置预览与持久章节索引（0.8.3）

## 目标

把“打开到可读页面”从 0.8.2 的约 2.2 s 压到 1 s 内，并保证从任意阅读进度继续时也能直接打开到目标章节。

## 问题

0.8.2 的 `openPreview()` 只读前 8 章，并且只在 `BookSource.localFile() != null` 时启用。通过系统文件选择器打开的 EPUB 是 `content://` URI，没有本地文件，因此实际用户路径根本没有走预览：

- 先完整读取 12.5 MB ZIP
- 再解析全部 50 个 XHTML
- 再为 113 万字构建富文本
- 首屏仍要 2.2 s 以上

即使预览命中，阅读到第 3000 页后再打开时，目标位置也不在前 8 章，预览会被拒绝。

## 实现

### 1. content URI 的一次性随机读缓存

`ContentBookSource.localFile()` 把 SAF 流复制成 app cache 中的本地文件：

- 文件名 = URI 的 SHA-256
- 同 URI、同大小直接复用
- 只保留最近 3 本、总计不超过 64 MB
- 预览读取时 `readAll()` 复用这份缓存，不再向 provider 读第二遍
- 没有调用 `localFile()` 的 TXT/PDF 等格式仍然只流式读一次，不产生缓存副本

### 2. 持久章节索引

`BookIndexStore` 在完整解析后保存每个 spine 章节的：

- 章节路径
- 全书字符起点
- 章节字符长度

数据只有几十条，写入 `filesDir/book-index/*.json`。下次打开时：

1. 读取索引
2. 用保存的字符偏移二分/倒序查找目标章节
3. 让预览从目标章节开始，而不是固定从第 0 章开始

### 3. 带全局偏移的章节窗口

`Chapter` 新增 `baseOffset`，表示该章文本在全书中的全局起点。`ReaderSurfaceView` 在内部使用章节局部偏移，对外继续使用全书偏移：

- `setContent(text, theme, initialCharOffset, baseOffset)`
- `goToCharOffset()` / `currentCharOffset()` / `PageInfo.charOffset` 全部是全书坐标
- 翻页、图片、样式、链接仍用章节局部坐标

因此预览可以从第 30 章开始，保存的 `1023508` 这样的全书偏移仍然准确落到同一页；完整书替换预览时也不需要重新计算位置。

`openPreview()` 新增 `startChapter`、`knownMarks`、字符预算三个输入：

- 从目标章节开始
- 目标章 + 后续章节累计到约 8 万字就停止，避免在大章节后面白读几章
- 如果没有索引，保持原来的前 8 章行为

### 4. 去掉重复 XHTML 解析

预览循环里已经解析过一次 XHTML，`buildDocument()` 又解析一次。现在把 `CachedChapter(html, rich)` 直接传进去，预览只解析一次。

另外把 `XhtmlText` 中每行都新建的 `Regex("[\\t ]+")` 提为常量，减少大章节的重复编译。

### 5. 图片位图复用

`LazyEpubDrawable` 增加按 `bookKey + resource` 索引的 24 MB `LruCache`。预览切到完整书时，当前页图片直接复用已解码位图，不会出现第二次弹图或空白页。

### 6. 预览页数显示

预览的 `pageCount` 只是窗口内页数，不是全书页数。预览期间顶栏显示 `1/…`，完整索引完成后显示真实页数，避免把 110 页误报成全书 4145 页。

## 真机结果

设备：OnePlus Ace 5（PKG110，Android 16/API 36）
书：12.5 MB EPUB，50 章，127 张图，1,131,577 字，完整索引 4145 页

| 场景 | 0.8.2 | 0.8.3 |
|---|---|---|
| 第 1 页首屏（可读，含整页图） | 约 2.2 s | **约 0.21 s** |
| 第 1 页，截图 @ 约 0.25 s | 加载态 | 图文完整 |
| 末尾“译后记”继续阅读 | 约 2.4 s | **约 0.75 s** |
| 冷启动 Activity `am start -W` | — | 142 ms |

## 仍未完成

- 完整解析仍会把整个 ZIP 读进内存并解析全部 XHTML（12.5 MB 书约 1.6–2.1 s）
- 完整富文本仍是全书一次性构建（约 1.2 s），完成后会替换预览
- 预览窗口前没有加载上一章，落在章节开头时不能向左翻
- 预览期间目录只有窗口内章节，完整目录要等后台替换
- `scripts/bench-open.ps1` 的单次 `uiautomator dump` 约 2.2 s，测出的 2.5 s 是工具上限，不是首屏时间
- TXT/HTML/Markdown 流式首屏、PDF 基准、持久页索引尚未做
