# M7a Release 测试构建（2026-11-08）

## 配置

- `versionCode 33`，`versionName 0.7.0`
- release：
  - `isMinifyEnabled = true`
  - `isShrinkResources = true`
  - `proguard-android-optimize.txt` + 项目规则
- 正式签名从 `keystore.properties` 读取；未提供时 release 未签名
- 本地验证用 `-Pinkreader.testReleaseSigning=true` 临时使用 debug keystore

## 构建

```powershell
.\gradlew.bat :app:assembleRelease "-Pinkreader.testReleaseSigning=true"
```
