# M4a PDF 渲染（2026-11-08）

## 范围

- `formats/pdf` provider：扩展名/mime 识别，固定页 BookDocument
- `PdfDocumentController`：PdfRenderer/FD 生命周期、串行渲染
- `PdfReaderScreen`：
  - 适配宽度
  - 页码 1/2
  - 上一页/下一页
  - 双指缩放 1×–4×、拖动
  - 双击 2×/还原
  - 夜间反色
- 非 seekable 源复制到 app cache；关闭时删除
- debug 样书 `app/src/debug/assets/sample.pdf`
