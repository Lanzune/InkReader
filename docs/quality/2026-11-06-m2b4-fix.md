# M2b4 页级字形安全区修复（2026-11-06）

## 为什么 M2b3 没彻底解决

`StaticLayout.setIncludePad(true)` 只给**整个布局的第一行和最后一行**加字体 padding，不会给分页后的每一页首尾行加。

因此：

- 第 2 页开始的第一行，仍然可能被页顶 clip 切掉 ascent；
- 任意一页的最后一行，仍然可能被页底 clip 切掉 descent。

## 正确修复

每一页单独计算字形安全区：

- `pageTopInset = ceil(-fontMetrics.top)`
- `pageBottomInset = ceil(fontMetrics.bottom)`
- 分页可用高度 = `contentHeight - pageTopInset - pageBottomInset`
- 绘制时先下移 `pageTopInset`，再按页首行 top 平移
- 页底 clip 保留 `pageBottomInset`，保证 descender 完整

这样不依赖 `includePad`，对所有页都成立。

同时保留：

- 顶部 96dp 控制栏/状态栏安全区
- 底部 52dp + 8dp 额外余量
- 导航栏隐藏/上滑临时呼出
